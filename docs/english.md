# Agent Loop Lab

**Maintain domain knowledge separately; keep a tightly coupled business decision with one agent by default.** When the next action depends on a fact just retrieved, a single agent with reliable tools completed our short tasks with fewer model calls. We did not find a general accuracy advantage for either topology.

**Delegation has a measurable cost on short tasks.** In a matched comparison with the same model and business tools, direct execution, a natural-language handoff, and a handoff with the original request and evidence each passed 6/6. The single loop used 16 model calls in total; each delegated variant used 25. The check covered when to act, when to refrain, and what the customer was told. On a separate frozen holdout of 12 distinct tasks repeated twice, tools alone, eager skills, on-demand skills and adaptive delegation each passed 24/24; adaptive delegation actually used a worker on only six runs. [Matched comparison](../fieldwork/2026-11-08/kit/README.md) · [Holdout results](../FAIR-RESULTS.md)

**Access to the right knowledge matters; how it is packaged is a separate decision.** On two company-specific SQL questions, both a Skill and a dictionary tool returning the same text produced correct queries on both database fixtures. Without the definitions the model asked for clarification. On the holdout subset with 24 manuals, loading on demand used 31.5% fewer tokens than preloading at the same pass count; on the separate three-manual subset it used 1.7% more. The subsets used different tasks, so these are within-subset comparisons, not a universal threshold. [SQL results](../fieldwork/2026-11-08/langchain-reference/README.md) · [Paired usage](../reports/fair-v2-resource-comparison.json)

**Judge what reaches the customer.** In a Japanese returns case, the specialist correctly supplied the delivery date and the deadline on both runs. The coordinator received both but omitted the delivery date in both final explanations. The business decision was still correct. Whether the omission matters depends on whether explaining the deadline is part of the service promised. [Case evidence](../fieldwork/2026-11-08/haty/README.md)

Start with one agent and reliable tools. Consider a separate worker when you need independent investigation, permission isolation or verification; test the claimed benefit against the baseline with the same total budget. This single-model, synthetic study does not establish a net benefit for those workloads or a production success rate.
