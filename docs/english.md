# Agent Loop Lab

When does delegating a decision help, and when does it just add a round trip? This independent study follows [Anthropic’s article](https://claude.com/resources/articles/building-agents-when-to-fold-subagents-into-your-main-agent-loop) from a support-task baseline through a failed stress test, a frozen holdout, and hands-on studies of four upstream projects. The [study register](studies/README.md) links the protocols, implementations, and evidence.

**What we observed:** On 12 synthetic holdout cases, each repeated twice, tools-only, eager skills, on-demand skills and adaptive delegation each passed 24/24. The tools-only loop used the fewest tokens; the adaptive configuration actually delegated on six runs. In a separate matched panel built on the official kit, free-form handoff, evidence-attached handoff and a folded loop each passed 6/6, using 25, 25 and 16 model calls. A Japanese retail panel showed why checking the trace matters: a specialist had supplied the correct delivery date, but the coordinator omitted it from the final explanation. Elsewhere a backend accepted a stale price proposal; withholding a final answer could not undo a write. These are different failure modes, not a single leaderboard.

**Interpretation:** Start simple for short, tightly coupled decisions; keep procedural knowledge independently maintainable. Test delegation on workloads where parallel investigation, isolation or verification could actually help. These are synthetic tasks using a Codex-backed model transport, not native Claude or production business outcomes. More repetitions of a few cases are not more independent cases.

**Verify without model access:** From a source checkout, run `python3 scripts/check_evidence.py`. Public per-run observations, frozen inputs and audit summaries support numeric checks.
