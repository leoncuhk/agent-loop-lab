# 公开研究版验收 · 2026-11-08

这次整理的基线是 [fieldwork-v1](https://github.com/leoncuhk/agent-loop-lab/tree/fieldwork-v1)。本版没有新跑模型来替换成绩。改动集中在文档结构、可分发的逐次观测、固定上游获取和公开核验。下列是已经做过的事，而不是日后运行计划。

| 检查对象 | 怎样核验 | 结果／未覆盖的边界 |
|---|---|---|
| 原有资产与冻结协议 | 整理前创建 Git bundle 并克隆恢复，原树对象完全相同。对照 Git 差异，核验源码、skills、依赖与封存题的指纹。 | S1–S3 的被测实现和旧基线未改；历史报告的旧字节按原路径和标签可查。 |
| 过去的正式结果 | 从当时的本地原始结果、调用记录与封存题再次运行独立验收器；对比整个输出 JSON，而非只比总分。 | 12 个独立题目真值、96 次任务通过证据验收，输出与[已发布审计](../../reports/fair-v2-final-independent-audit.json)一致。跨项目原始回执重新核对，亦与[既有账本](../../fieldwork/2026-11-08/EVIDENCE.json)一致。 |
| 可被读者复算的早期观察 | 白名单导出三个原始结果文件的 145 行，只留固定类别和数字。区分未启动、主动停止、服务超时与业务失败。 | 核出客服两批 64、48 行；困难实验 33 行。公开摘要不能倒推出原始对话，不以数值一致代替原始事实真实性。 |
| 科学口径审查 | 拿首页和协议逐项对照，按任务 ID、组、重复核对配对，构造“保持总数、替换整道题”的反例。 | 待发布核验器起初会接受不在 sealed 文件里的整组题号，另会接受被放大的 aidless 样本数；现已绑定原计划，负例在[回归测试](../../tests/test_public_evidence.py)中。实际原批次题号、样本数正确；没有修改原分数。 |
| 第三方开箱使用 | 不复制原始运行目录，独立 clone，Python 3.12 新环境按锁安装，执行公开核验、全部测试、lint 和 CLI 任务列表。 | 53 个测试通过。用新缓存取固定 kit、aidless，完成其离线步骤；另复跑 commerce 完整离线套件（1104 通过、1 跳过），严格价格负例仍复现。修复了新检出尚无 runs 父目录时 commerce 启动失败。没有把上述工程数字计入模型效果。 |
| 发布面 | 枚举 Git 当前文件、检查 Markdown 相对路径、解析源码和 JSON、检查 shell 语法；检查待发布历史中的路径、凭证特征与额外数据库文件。 | 只同步研究仓、代码、合成数据和核验摘要；原始运行、真实模型输入输出、账户材料、虚拟环境和上游克隆不分发。模式检查不能证明所有字符串都绝对无敏感性。 |

本版没有做跨模型独立复现实验、生产安全认证、真实商业效果验证或无条件架构排名。若这些才是应用决策需要的证据，应该按[方法指南](../method.md)重新选任务和验收标准。
