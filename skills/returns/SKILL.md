# 退货办理

1. 确定用户要退哪一个订单，以及动作是无条件、带条件，还是仅咨询。查询意图只读取事实。
2. 查询目标订单和退货政策，核对身份、状态和收货天数。金额从订单读取。
3. 如果动作依赖另一订单的物流，先取该订单 ETA 并判断用户条件。日期未知或条件不成立时保留原状。
4. 只有用户明确要求且条件满足时调用 create_return。工具通过外部审批后才会写入；审批拒绝时结束为 blocked，等待时为 needs_approval。
5. 创建成功后，完成状态为 completed，将实际 receipt_id 放入 receipt_ids，并引用工具返回的退货和退款事实。
6. 政策不符合时为 blocked，提供能够说明原因的订单事实。重复请求使用既有回执。

完成条件：该做的动作具有真实回执；未获授权或条件未满足的动作没有执行；最终 facts 保留用户问到的事实及动作结果。
