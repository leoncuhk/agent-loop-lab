# 物流查询与条件判断

1. 分开识别用户需要的订单状态和预计送达日期。get_order 提供状态；get_shipping 才提供 ETA。
2. 对所有涉及截止时间的决定，取得对应新订单的真实 ETA。运单号、已发货或收货天数不能代替 ETA。
3. 日期比较保留“之前”与“当天或之前”的差别。ETA 为 unknown 时，条件尚未证实。
4. 原样保留“只有……才……”以及“无论……都……”的条件关系；新旧订单可能不同。
5. 将用到的状态和 ETA 的 key/value/source 放进最终 facts，交回后续动作判断所需的信息。

完成条件：用户请求的物流事实都有对应工具证据；涉及后续动作时，能明确判断条件成立、未成立或未知。
